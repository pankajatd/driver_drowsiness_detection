## 1. Defect Description
When the user selected the preset scenario **"Driver Yawning & Fatigue (Early Warning)"** from the sidebar dropdown in the Streamlit application, the preview frame and telemetry engine reported an alert, attentive driver with mouth closed (`MAR: 0.42`) and status `ATTENTIVE (Driver Alert)` instead of displaying the yawning driver with an early warning alert banner.

## 2. Steps to Reproduce
1. Launch the Streamlit application via `streamlit run src/app.py`.
2. In the sidebar dropdown, select **"Driver Yawning & Fatigue (Early Warning)"**.
3. Observe the displayed media container and telemetry dashboard.
4. Note that the displayed driver has mouth closed, eyes wide open, and the alert banner shows green `ATTENTIVE`.

## 3. Expected vs. Actual Behavior
- **Expected:** Selecting the Yawning scenario should immediately display the authentic yawning driver on Frame 0, evaluate Mouth Aspect Ratio (`MAR >= 0.65`), and trigger the `DROWSY (Early Warning)` status.
- **Actual:** The system displayed an alert driver on Frame 0 with `MAR = 0.42` and status `ATTENTIVE`.

## 4. Root Cause Analysis
In the synthetic preset video generation script (`deploy_in_car_presets.py`), the developer implemented a lead-in transition loop:
```python
for i in range(total_frames):  # 90 frames total
    if i < 20:
        frame = alert_bgr.copy()  # Developer inserted 20 alert frames at video start
    else:
        frame = yawn_bgr.copy()   # Yawn frames only started from frame 20
```
Because Streamlit's media pipeline freeze-evaluates Frame 0 upon preset selection, the perception engine analyzed `alert_bgr` instead of `yawn_bgr`. To the user, selecting the preset appeared broken because the yawn was delayed past frame 20.

## 5. Developer Resolution (Applied by Software Developer Agent)
1. **Refactored Video Generation Logic:**
   - Removed the `if i < 20: alert_bgr` condition in `deploy_in_car_presets.py`.
   - Re-rendered `data/sample_presets/driver_yawn.mp4` so that 100% of frames (from Frame 0 to Frame 89) contain the authentic yawning driver (`yawn_bgr`) with realistic road vibration jitter.
2. **Enhanced UI Architecture (`src/app.py`):**
   - Introduced dual-tab inspection defaulting to **`📷 Single HD Cabin Photo`**, ensuring that selecting a scenario immediately analyzes and displays the full-resolution photograph on Frame 0 without video streaming latency.
   - Dedicated second tab **`🎬 In-Cabin Video Stream`** runs continuous frame-by-frame analysis with smooth FPS pacing.
